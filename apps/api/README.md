# `@academistream/api`

NestJS HTTP API for Academistream (auth, content, training, org, quotas).

## Run

From the monorepo root (after Docker Compose + `.env`):

```bash
npm run api:dev
```

Health: `http://localhost:3000/health`

See the root [README](../../README.md) and [technical documentation](../../docs/TECHNICAL.md).
