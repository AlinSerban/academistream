# Definition of Done

A story is done when:

1. Acceptance criteria on the Trello card are met
2. Relevant tests exist for critical paths (or N/A is noted for docs-only work)
3. No secrets committed
4. Schema changes include migrations (when we have a DB schema)
5. README / run docs updated if how-to-run changed
6. Card moved to **Review** for PO acceptance

## Branch naming (light)

`feature/S0-02-compose`, `feature/S1-01-tenants`, etc.
